# Analysis Report Minimum Contents

For every figure record:

- system and trajectory path;
- frame range and time stride;
- PBC treatment;
- fitting group and analysis group;
- units and selection definitions;
- mean, spread, and important time windows;
- direct observation and interpretation separately.

For comparisons, keep trajectory length, sampling interval, fitting group, reference structure, y-axis units, and plot scale consistent. Include a short limitations paragraph for single replicas, late trajectory events, and endpoint free-energy methods.
